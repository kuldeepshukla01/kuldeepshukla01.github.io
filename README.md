## 🏛️ Architecture & Visual Engineering

### 1. Three.js 3D Refractive Crystal Core
- **Physical Glass Crystal**: Central dodecahedron utilizing `MeshPhysicalMaterial` with realistic physical transmission (`transmission: 0.95`), internal roughness, silver specular highlights, and high-ior refraction.
- **Wireframe Hex/Icosahedron Outer Cage**: High-precision protective shield with inverted internal wireframe geometry.
- **Concentric Gyroscopic Orbital Rings**: Silver metallic laser coordinate rings orbiting on orthogonal 3D axes.
- **2,500-Node Swirling Vortex**: Dynamic spiraling particle field responding to mouse velocity, scroll delta, and interactive charge dynamics.
- **Tactical Threat Nodes**: 3D interactive constellation points representing core toolsets (`Burp Suite`, `Metasploit`, `Ghidra`, `Wireshark`, `Nmap`, `OWASP ZAP`, `XGBoost NIDS`, `Frida`).

### 2. GSAP 3 & Scrollytelling Choreography
- **Hatom Preloader**: Precise numeric counter (00% to 100%) surrounded by a circular egg progress SVG ring, resolving into a click-to-enter tactical authorization gate.
- **5-Phase Narrative Flow**:
  1. `PHASE 01 // THE GENESIS` — Hero introduction, live status indicator, and dynamic typography.
  2. `PHASE 02 // THE ARCHITECTURE` — Offensive security philosophy, core metrics (14 Attack Classes, 97%+ Accuracy, OWASP MASVS, 100% Client-Side Crypto), and verified credentials.
  3. `PHASE 03 // THE ARSENAL` — Deep dive into verified security projects:
     - **1DayCrew AI** — Machine Learning Network Intrusion Detection System trained on real-world traffic with NFStream, XGBoost, and SHAP explainability.
     - **Android Bug Bounty Hunter** — Mobile application penetration testing framework assessing OWASP MASVS vulnerabilities, storage security, and Frida instrumentation.
     - **Aegis Recon & Surface Scanner** — Automated reconnaissance suite orchestrating asynchronous port enumeration, DNS permutation, and subdomain discovery.
     - **Web Crypto Toolkit** — Zero-dependency cryptographic validation suite running purely in the browser.
  4. `PHASE 04 // THE LIVE LAB` — Functional interactive offensive security testing tools:
     - Cryptographic Hash Generator (SHA-1, SHA-256)
     - Encoder / Decoder (Base64, ROT13)
     - Password Entropy & HIBP API Pwned-Password Check
     - Breach Surface Exposure Lookup
     - Real-time Client Network & Device Telemetry
  5. `PHASE 05 // THE NEXUS` — Direct contact channels, CV download link (`Kuldeep_Shukla_CV.pdf`), and social networks (GitHub, LinkedIn).
- **Interactive "HOLD TO EXPLORE" Experience**: Long-press interaction charging the 3D core with rising frequency audio, particle vortex acceleration, and a radial shockwave release.
- **Editorial Fullscreen Navigation**: Hatom-inspired minimalist navigation menu with sound toggle and direct jump anchors.

### 3. Procedural Web Audio Engine
- Built entirely with the browser **Web Audio API** (zero external sound assets):
  - Ambient 40Hz server drone with sub-bass resonance.
  - Tactical hover clicks and route transition warp sweeps.
  - Rising frequency charge and resonant detonation shockwave chord for the long-press interaction.

The repository is configured to deploy directly to GitHub Pages:
